# Nexa Tower — clone + redesign + commerce

## Design direction
Warm arcade-brutalist editorial. Espresso ink `#0B0A09`, bone `#F4EEE3`,
tangerine `#FF5A1F`, amber `#FFC247`, clay `#8A4B2A`.
Type: Bricolage Grotesque (display) / Instrument Sans (body) / JetBrains Mono (labels).
Sharp 2px corners, grain overlay, ticker marquees, oversized numerals, asymmetric grids.
